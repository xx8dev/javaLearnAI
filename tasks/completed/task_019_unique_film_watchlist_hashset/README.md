# Задача №19 — Как не добавить один фильм дважды?

**Сложность:** начальная, следующий шаг в теме коллекций.

**Тема:** набор уникальных кодов фильмов с помощью `HashSet`.

## Что закрепляем и изучаем

- Закрепляем: классы, инкапсуляцию, строки, обобщённые коллекции, `equals()` и `hashCode()`.
- Новое понятие: `HashSet` — коллекция, которая хранит только уникальные значения. Она не обещает порядок элементов и не обращается к ним по индексам.

`HashSet` использует `hashCode()` и `equals()`, чтобы распознавать дубликаты. Поэтому два разных объекта `String` с одинаковым текстом считаются одним и тем же кодом.

## Учебный пример: занятые места в зале

```java
import java.util.HashSet;

public class SeatReservationDemo {
    public static void main(String[] args) {
        HashSet<String> occupiedSeats = new HashSet<>();
        boolean firstReservation = occupiedSeats.add("B4");
        boolean duplicateReservation = occupiedSeats.add("B4");
        boolean isOccupied = occupiedSeats.contains("B4");
        boolean wasRemoved = occupiedSeats.remove("B4");
        System.out.println(firstReservation + ", " + duplicateReservation + ", "
                + isOccupied + ", " + wasRemoved + ", мест: " + occupiedSeats.size());
    }
}
```

- `HashSet<String>` создаёт набор строковых кодов; изначально он пуст.
- Первый `add("B4")` добавляет место и возвращает `true`.
- Второй такой же `add` ничего не дублирует и возвращает `false`.
- `contains` проверяет, есть ли место в наборе; `remove` удаляет его и сообщает, получилось ли это.
- После удаления `size()` вернёт `0`; программа выведет `true, false, true, true, мест: 0`.

Полный путь: код места передаётся в набор → набор добавляет его только один раз → следующие операции проверяют и удаляют тот же код → результат и размер выводятся. В задаче будет тот же принцип для кодов фильмов.

## Условие

Создай публичный класс `FilmWatchlist` в пакете `learning.task019`. Он хранит коды фильмов в одном закрытом поле `HashSet<String>`.

Внешний контракт:

```java
public FilmWatchlist()
public boolean addFilmCode(String filmCode)
public boolean containsFilmCode(String filmCode)
public boolean removeFilmCode(String filmCode)
public int getFilmCount()
```

Правила:

- Код фильма во всех методах должен быть не `null` и не пустой строкой. Иначе выбрасывается `IllegalArgumentException`.
- `addFilmCode` возвращает `true`, если код добавлен впервые, и `false`, если такой код уже есть.
- `containsFilmCode` сообщает, хранится ли код в наборе.
- `removeFilmCode` возвращает `true`, если код был удалён, и `false`, если его не было.
- Равные по содержимому коды считаются одинаковыми; регистр учитывается. После удаления код можно добавить заново.
- `getFilmCount()` возвращает число уникальных кодов. Порядок хранения не определён; набор не выдаётся вызывающему коду и ничего не печатает.

### Примеры

| Операции | Результат |
|---|---|
| Первый раз добавить `"FILM-4"` | `true`, размер `1` |
| Повторно добавить `"FILM-4"` | `false`, размер остаётся `1` |
| Удалить существующий `"FILM-4"` | `true`, размер `0` |

## Критерии готовности

- Класс хранит коды в `HashSet<String>` и не предоставляет доступ к набору.
- Повторный код не добавляется, а операции добавления, поиска и удаления возвращают правильные `boolean`.
- Проверены равные строки, регистр, пустой набор, недопустимые коды и независимость объектов.
- Количество соответствует числу уникальных кодов, методы не печатают результат.
- Все автоматические тесты проходят.
