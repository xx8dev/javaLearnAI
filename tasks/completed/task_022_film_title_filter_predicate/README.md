# Задача №22 — Как отобрать фильмы по разным условиям?

**Сложность:** начальная, передача условия проверки в метод.

**Закрепляем:** интерфейсы, `ArrayList`, циклы, работу с параметрами и возвращаемыми значениями.

**Новые понятия:** функциональный интерфейс `Predicate<T>` и лямбда-выражение. `Predicate<T>` — интерфейс из стандартной библиотеки Java с методом `test`, который принимает значение типа `T` и возвращает `boolean`. Лямбда позволяет коротко передать реализацию такого условия.

## Зачем это нужно

Киносервису нужно отбирать названия по разным запросам: например, по длине или по первой букве. Сам обход списка остаётся тем же, а вызывающий код передаёт нужное правило. Так не нужно создавать отдельный метод для каждого условия.

## Учебный пример: выбрать цены до бюджета

```java
import java.util.ArrayList;
import java.util.List;
import java.util.function.Predicate;

public class GamePriceSelector {
    public static List<Integer> select(List<Integer> prices, Predicate<Integer> rule) {
        List<Integer> selected = new ArrayList<>();
        int index = 0;
        while (index < prices.size()) {
            int price = prices.get(index);
            if (rule.test(price)) {
                selected.add(price);
            }
            index++;
        }
        return selected;
    }

    public static void main(String[] args) {
        List<Integer> prices = List.of(150, 600, 250);
        Predicate<Integer> withinBudget = price -> price <= 300;
        List<Integer> affordable = select(prices, withinBudget);
        System.out.println(affordable);
    }
}
```

- `Predicate<Integer>` описывает вопрос с ответом `true` или `false` для цены.
- `price -> price <= 300` — лямбда: слева имя входного значения, справа выражение, которое возвращает `boolean`.
- Для каждой цены вызывается `rule.test(price)`. Если ответ `true`, цена добавляется в новый список.
- В `main` вход `[150, 600, 250]` проходит через правило «не больше 300»; на экран выводится `[150, 250]`.
- Метод не знает, какое именно правило передали: можно передать другое условие, не меняя обход списка.

## Условие

Создай в пакете `learning.task022` публичный класс `FilmTitleFilter` с публичным статическим методом:

```java
List<String> filter(List<String> titles, Predicate<String> condition)
```

Метод должен пройти по названиям в исходном порядке, передать каждое название в `condition.test(...)` и добавить в результат те названия, для которых условие вернуло `true`.

- Верни новый список и не изменяй исходный.
- Порядок подходящих названий должен совпадать с порядком в исходном списке.
- Пустой список на входе даёт пустой список.
- `titles`, `condition` и каждое название в списке не должны быть `null`; при нарушении выброси `IllegalArgumentException`.
- Если условие не выбрало ни одного названия, верни пустой список.

## Примеры

Для названий `Dune`, `Solaris`, `It`, `Arrival` и условия `title -> title.length() >= 5` результатом будут `Solaris`, `Arrival`.

Для тех же названий и условия `title -> title.startsWith("Z")` результатом будет пустой список.

## Ограничения и готовность

- Не добавляй проверку конкретного текста условия через `if`; проверяй каждое название вызовом `condition.test(...)`.
- Не используй Stream API в этой задаче: отбор выполни знакомым циклом, чтобы сосредоточиться на `Predicate` и лямбде.
- Проверь работу с несколькими разными лямбда-условиями.
