# Задача №1 — Первое пополнение игрового счёта

**Сложность:** начальная.  
**Тема:** финансовые операции в игровом приложении.

## Что изучаем

- Закрепляем: пока нет подтверждённых навыков; это первая задача.
- Новые понятия: целое число `int`; метод с параметрами и возвращаемым значением.

Баланс и пополнение в этой задаче выражены целым количеством рублей, поэтому подходит `int`. Метод позволяет передать числа в расчёт и получить ответ, который затем можно использовать в другой части программы.

## Условие

Игровой счёт хранит баланс в целых рублях. После пополнения нужно вычислить новый баланс. Например, к 1 200 рублям добавили 250 рублей — после операции на счёте 1 450 рублей.

Реализуй этот расчёт в самостоятельно созданном классе `Solution`.

### Внешний контракт

Создай пакет `learning.task001`, публичный класс `Solution` и в нём метод с точной сигнатурой:

```java
public static int calculateBalanceAfterTopUp(int currentBalanceRubles, int topUpRubles)
```

Метод должен вернуть сумму текущего баланса и пополнения. Он не должен печатать результат в консоль.

### Примеры

| Текущий баланс | Пополнение | Результат |
|---:|---:|---:|
| 1 200 | 250 | 1 450 |
| 0 | 730 | 730 |
| 900 | 0 | 900 |

## Ограничения и готовность

- Оба входных значения находятся в диапазоне от `0` до `1 000 000 000` включительно.
- Сумма помещается в `int`.
- Верни результат из метода; не используй ввод с клавиатуры и вывод в консоль.
- Решение должно находиться в отдельном файле `Solution.java`, а не во вложенном классе.
- Задача готова, когда все тесты проходят и поведение совпадает с контрактом.

## Учебный пример: свободные места в кинозале

Здесь метод считает свободные места. Это другой расчёт: из общего числа мест вычитается число проданных билетов.

```java
public class SeatExample {
    public static void main(String[] args) {
        int freeSeats = countFreeSeats(50, 18);
        System.out.println(freeSeats);
    }

    public static int countFreeSeats(int totalSeats, int soldSeats) {
        int remaining = totalSeats - soldSeats;
        return remaining;
    }
}
```

- `int freeSeats = countFreeSeats(50, 18);` передаёт числа `50` и `18` методу и сохраняет возвращённый ответ в переменную `freeSeats`.
- `public class SeatExample` объявляет класс; если сохранишь этот пример отдельно, имя файла должно быть `SeatExample.java`.
- `public static void main(String[] args)` — точка, с которой Java запускает этот пример. `void` означает, что `main` сам не возвращает результат. В задаче такой метод создавать не нужно.
- `public static int countFreeSeats(...)` объявляет метод: `public` разрешает вызывать его из теста, `static` позволяет вызвать его через имя класса, а `int` перед скобками означает, что метод возвращает целое число. Параметры внутри скобок получают входные значения.
- `int remaining = totalSeats - soldSeats;` создаёт локальную переменную и записывает в неё результат вычитания.
- `return remaining;` возвращает значение вызывающему коду.
- `System.out.println(freeSeats);` показывает полученное значение. При запуске примера на экран выводится `32`.

Полный путь данных здесь такой: в метод поступают `50` и `18` → Java вычитает `18` из `50` → метод возвращает `32` → `println` печатает `32`.

В твоей задаче тест передаст методу баланс и сумму пополнения, получит целое число и сравнит его с ожидаемым результатом. Проверки уже подготовлены; свою проверку вручную писать не нужно.

## Файлы и запуск

Самостоятельно создай файл решения:

```text
src/main/java/learning/task001/Solution.java
```

Автоматические тесты тренера находятся здесь:

```text
src/test/java/learning/task001/Task001GameBalanceTest.java
```

Запусти все тесты из корня проекта:

```shell
.\mvnw.cmd test
```

До создания класса `Solution` тесты ожидаемо не скомпилируются. Это начальное состояние задачи; тесты станут зелёными после реализации контракта.
