# Задача №9 — Как получить понятное описание кинобилета?

**Сложность:** начальная.

**Тема:** билет на кинопоказ.

## Что закрепляем и изучаем

- Закрепляем: классы и объекты, конструктор, приватное состояние, нестатические методы и работу со строками.
- Новое понятие: переопределение `toString()` — метода, который каждый класс получает от `Object`.

У любого объекта есть `toString()`, но стандартное представление обычно не объясняет, что объект хранит. Переопределив метод, можно задать читаемое описание. Например, когда объект передают в `System.out.println`, Java вызывает его `toString()` и печатает возвращённую строку.

## Условие

Создай класс `CinemaTicket` в пакете `learning.task009`. Он описывает билет и должен возвращать его данные в строке точно по формату:

```text
Фильм: <название> | Ряд: <ряд> | Место: <место> | Цена: <цена> руб.
```

Внешний контракт:

```java
public CinemaTicket(String movieTitle, int row, int seat, int priceRubles)
public String toString()
```

Переопредели унаследованный метод `toString()`. Данные билета храни в приватном состоянии объекта. Для разных объектов должны сохраняться их собственные значения. Не печатай строку внутри класса — `toString()` возвращает её вызывающему коду.

Название гарантированно непустое. Оно может содержать пробелы, знаки препинания и буквы разных алфавитов; верни его без изменений. Ряд находится в диапазоне `1..30`, место — `1..50`, цена — `0..100_000` рублей. Проверять аргументы конструктора не требуется.

### Примеры

- Название `Интерстеллар`, ряд `3`, место `12`, цена `650`:

  ```text
  Фильм: Интерстеллар | Ряд: 3 | Место: 12 | Цена: 650 руб.
  ```

- Название `Амели`, ряд `1`, место `1`, цена `0`:

  ```text
  Фильм: Амели | Ряд: 1 | Место: 1 | Цена: 0 руб.
  ```

- Название `Планета Земля`, ряд `30`, место `50`, цена `100000`:

  ```text
  Фильм: Планета Земля | Ряд: 30 | Место: 50 | Цена: 100000 руб.
  ```

## Учебный пример: трек в плейлисте

В примере `PlaylistTrack` хранит название трека и длительность. Переопределённый `toString()` формирует описание; `println` получает объект и печатает это описание.

```java
public class PlaylistTrack {
    private String title;
    private int durationSeconds;

    public PlaylistTrack(String title, int durationSeconds) {
        this.title = title;
        this.durationSeconds = durationSeconds;
    }

    @Override
    public String toString() {
        return title + " (" + durationSeconds + " сек.)";
    }

    public static void main(String[] args) {
        Object track = new PlaylistTrack("Ночной маршрут", 215);
        System.out.println(track);
    }
}
```

- `private` закрывает данные трека для прямого изменения из другого класса.
- Конструктор получает название и длительность и сохраняет их в полях созданного объекта.
- `@Override` просит компилятор проверить, что ниже действительно переопределён унаследованный метод с нужной сигнатурой.
- `toString()` соединяет сохранённые значения в одну строку и возвращает её; сам метод ничего не печатает.
- Переменная `track` имеет тип `Object`, но в ней лежит объект `PlaylistTrack`. При `System.out.println(track)` Java вызывает переопределённый метод этого объекта. На экране появится `Ночной маршрут (215 сек.)`.

Путь данных: конструктор получает название и длительность → сохраняет их в объекте → `println` запрашивает строковое представление объекта → `toString()` возвращает описание → терминал показывает описание. В задаче примени тот же приём к данным билета; автоматические тесты проверят формат, границы значений, независимость объектов и вызов через ссылку типа `Object`.

## Ограничения и готовность

- Создай решение самостоятельно; заготовки класса в `src/main` нет.
- Для каждого билета возвращай точный формат, включая пробелы, разделители и суффикс `руб.`.
- Повторный вызов `toString()` для того же билета должен возвращать то же описание.
- Класс не должен читать ввод или печатать в консоль.
- Задача готова, когда проходят все автоматические тесты и соблюдены ограничения условия.

## Файлы и запуск

Создай класс решения самостоятельно:

```text
src/main/java/learning/task009/CinemaTicket.java
```

Автоматические тесты тренера:

```text
src/test/java/learning/task009/Task009CinemaTicketTest.java
```

Запусти тесты из корня проекта:

```shell
.\mvnw.cmd test
```

До создания `learning.task009.CinemaTicket` тесты ожидаемо не скомпилируются. После создания класса тесты проверят обычный чек, граничные числа, повторные вызовы, независимые объекты, переопределение `toString()` и отсутствие ввода/вывода.
