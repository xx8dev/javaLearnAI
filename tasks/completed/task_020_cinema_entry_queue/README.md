# Задача №20 — Кто следующим попадёт на кинопоказ?

**Сложность:** начальная, очередь как новый способ работы с коллекцией.

**Тема:** последовательность посетителей по правилу «кто пришёл раньше — обслуживается раньше».

## Что закрепляем и изучаем

- Закрепляем: классы, инкапсуляцию, строки, проверку входных данных и работу с коллекциями.
- Новое понятие: очередь FIFO (first in, first out) — первым выходит элемент, который раньше остальных вошёл. Для неё используем `ArrayDeque`.

Очередь подходит для входа в зал: посетители встают в конец линии, а контролёр приглашает человека с начала. В отличие от `ArrayList`, здесь обычно не обращаются к произвольному индексу.

## Учебный пример: линия у входа

```java
import java.util.ArrayDeque;

public class EntryLineDemo {
    public static void main(String[] args) {
        ArrayDeque<String> line = new ArrayDeque<>();
        line.addLast("Мира");
        line.addLast("Лев");
        String next = line.peekFirst();
        String invited = line.removeFirst();
        System.out.println(invited + " → " + line.peekFirst() + "; в линии: " + line.size());
    }
}
```

- `ArrayDeque<String>` создаёт пустую двустороннюю очередь строк; для этой задачи мы используем её как обычную линию.
- `addLast` ставит посетителя в конец: сначала Миру, затем Льва.
- `peekFirst` смотрит, кто стоит первым, и не удаляет этого человека.
- `removeFirst` приглашает первого посетителя и убирает его из очереди.
- После этого `line.size()` равен `1`, а программа выводит `Мира → Лев; в линии: 1`.

Путь данных: имена добавляются в конец → очередь сохраняет порядок → просмотр головы показывает следующего → вызов удаляет его → следующий человек становится первым. В задаче ты создашь класс, который управляет такой очередью.

## Условие

Создай публичный класс `CinemaEntryQueue` в пакете `learning.task020`. Он хранит имена посетителей в одном закрытом поле `ArrayDeque<String>`.

Внешний контракт:

```java
public CinemaEntryQueue()
public void joinLine(String guestName)
public String peekNextGuest()
public String callNextGuest()
public int getGuestCount()
```

Правила:

- Имя при входе не может быть `null` или пустой строкой; иначе `joinLine` выбрасывает `IllegalArgumentException` и очередь не меняется.
- `joinLine` добавляет одного посетителя в конец. Одинаковые имена могут встретиться несколько раз: это разные места в очереди.
- `peekNextGuest` возвращает имя первого посетителя, не удаляя его.
- `callNextGuest` возвращает и удаляет первого посетителя.
- Если очередь пуста, `peekNextGuest` и `callNextGuest` возвращают `null`.
- `getGuestCount()` возвращает текущее количество посетителей. Объект не отдаёт наружу очередь, очереди разных объектов независимы, методы ничего не печатают.

### Примеры

| Действия | Результат |
|---|---|
| Добавить `"Мира"`, затем `"Лев"`, вызвать следующего | Возвращается `"Мира"`; первым остаётся `"Лев"` |
| Посмотреть следующего, не вызывая его | Возвращается первый посетитель, количество не меняется |
| Вызвать следующего из пустой очереди | `null` |

## Критерии готовности

- Посетители обслуживаются в порядке FIFO; просмотр следующего не меняет очередь, вызов удаляет его.
- Пустая очередь возвращает `null`, а неверное имя отклоняется без изменения состояния.
- Проверены порядок, повторы, количество, независимость объектов и закрытое хранение `ArrayDeque<String>`.
- Методы не печатают результат; все автоматические тесты проходят.
