# Задача №17 — Как управлять списком цен в цифровой корзине?

**Сложность:** начальная, первый шаг от массивов к коллекциям.

**Тема:** изменяемый список цен цифровых покупок.

## Что закрепляем и изучаем

- Закрепляем: классы, инкапсуляцию, циклы, методы, типы-обёртки и обобщённую запись `ArrayList<Integer>`.
- Новое понятие: `ArrayList` — список, который может расти и уменьшаться при добавлении и удалении элементов. В отличие от массива, его размер не задаётся заранее.

## Учебный пример: плейлист

```java
import java.util.ArrayList;

public class PlaylistExample {
    public static void main(String[] args) {
        ArrayList<String> tracks = new ArrayList<>();
        tracks.add("Тема фильма");
        tracks.add("Тема игры");
        String firstTrack = tracks.get(0);
        tracks.remove(0);
        System.out.println(tracks.size() + ": " + tracks.get(0));
    }
}
```

- `ArrayList<String>` создаёт список строк; пустые скобки означают, что в начале элементов нет.
- `add` добавляет строки в конец списка. После двух вызовов размер списка равен двум.
- `get(0)` читает первый элемент, потому что индексы, как и в массиве, начинаются с нуля.
- `remove(0)` удаляет первый элемент; бывший второй становится элементом с индексом `0`.
- `size()` возвращает текущий размер. На экран выводится `1: Тема игры`.

## Условие

Создай публичный класс `DigitalBasket` в пакете `learning.task017`. Корзина хранит цены цифровых товаров в порядке добавления. Для хранения используй одно закрытое поле `ArrayList<Integer>`; не возвращай наружу ссылку на этот список.

Внешний контракт:

```java
public DigitalBasket()
public void addPrice(int priceRubles)
public int getPriceCount()
public int getPriceAt(int index)
public int removePriceAt(int index)
public long getTotalRubles()
```

Правила:

- Цена каждого товара находится в диапазоне `0..1_000_000` включительно. Для цены вне диапазона `addPrice` выбрасывает `IllegalArgumentException` и не меняет корзину.
- Повторяющиеся цены и цена `0` разрешены.
- `getPriceCount()` возвращает количество позиций, а `getPriceAt(index)` — цену по индексу.
- `removePriceAt(index)` удаляет цену, возвращает её, а последующие позиции сдвигаются на один индекс влево.
- Если индекс для чтения или удаления меньше нуля либо не меньше количества позиций, выбрасывается `IndexOutOfBoundsException`.
- `getTotalRubles()` возвращает сумму всех цен типом `long`, в том числе когда она больше максимума `int`.
- Список не печатается и не выдаётся вызывающему коду; каждый объект корзины хранит свои позиции отдельно.

### Примеры

| Действия | Содержимое корзины | Количество | Сумма |
|---|---|---:|---:|
| Добавить `350`, затем `700` | `[350, 700]` | `2` | `1050` |
| Добавить `0` | `[0]` | `1` | `0` |
| Добавить `100`, `250`, удалить позицию `0` | `[250]` | `1` | `250` |

## Критерии готовности

- Корзина хранит цены в `ArrayList<Integer>` и не открывает список для внешнего изменения.
- Добавление, чтение и удаление сохраняют порядок и корректно обновляют количество и сумму.
- Проверяются допустимые границы цены, ошибочные цены и индексы, пустая корзина и сумма больше `int`.
- Разные объекты корзины независимы, методы не печатают результат.
- Все автоматические тесты проходят.
