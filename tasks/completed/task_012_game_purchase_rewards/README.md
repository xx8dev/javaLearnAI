# Задача №12 — Сколько бонусных баллов начислить за покупку в игровом магазине?

**Сложность:** начальная, новый шаг после классов, объектов и перечислений.

**Тема:** бонусные баллы за покупки в игровом магазине.

## Что закрепляем и изучаем

- Закрепляем: `int`, целочисленную арифметику, методы и проверки `if`.
- Новые понятия: `static` и константы `static final`.

`static` означает, что поле или метод относится к классу целиком, а не к отдельному объекту. Поэтому статический метод вызывают через имя класса, например `RouteReward.calculatePoints(350)`, и для такого вызова не нужно создавать объект.

`final` запрещает изменить значение после присваивания. Постоянное общее значение часто объявляют как `static final`; имена таких констант принято писать заглавными буквами с подчёркиваниями.

## Учебный пример: баллы за пройденное расстояние

```java
class RouteReward {
    static final int KILOMETERS_PER_POINT = 100;

    static int calculatePoints(int kilometers) {
        return kilometers / KILOMETERS_PER_POINT;
    }
}

public class Demo {
    public static void main(String[] args) {
        int routeKilometers = 375;
        int points = RouteReward.calculatePoints(routeKilometers);
        System.out.println(points);
    }
}
```

- `KILOMETERS_PER_POINT` — одно общее неизменяемое правило класса.
- `calculatePoints` — статический метод: получает число километров и возвращает число полных отрезков по 100 километров.
- `routeKilometers` хранит входные данные `375`; вызов `RouteReward.calculatePoints(routeKilometers)` передаёт их методу без создания объекта.
- Целочисленное деление даёт `3`, а `println` показывает это значение в консоли.

## Условие

Создай публичный класс `GamePurchaseRewards` в пакете `learning.task012`. Класс рассчитывает бонусные баллы за сумму покупки в рублях.

Внешний контракт:

```java
public static final int RUBLES_PER_REWARD_STEP = 250;
public static final int POINTS_PER_REWARD_STEP = 10;
public static int calculateRewardPoints(int purchaseAmountRubles)
```

За каждый полный шаг покупки в 250 рублей начисляется 10 баллов. Остаток меньше 250 рублей не учитывается. Например, за 740 рублей начисляется 20 баллов.

Метод возвращает `0`, если сумма меньше `0` или больше `100_000`. Допустимый диапазон — от `0` до `100_000` рублей включительно. Метод ничего не печатает.

### Примеры

| Сумма покупки | Бонусные баллы |
|---:|---:|
| `0` | `0` |
| `249` | `0` |
| `250` | `10` |
| `740` | `20` |
| `100_000` | `4_000` |
| `-1` или `100_001` | `0` |

## Критерии готовности

- В классе есть две указанные публичные константы с модификаторами `static final` и указанными значениями.
- Метод `calculateRewardPoints` публичный и статический.
- Расчёт учитывает только полные шаги покупки; неправильная сумма даёт `0`.
- Класс не хранит состояние покупки в нестатических полях и не выводит результат в консоль.
- Все автоматические тесты проходят.
