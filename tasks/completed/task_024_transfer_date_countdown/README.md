# Задача №24 — Сколько дней осталось до перевода?

**Сложность:** начальная, работа с календарными датами.

**Закрепляем:** методы, проверки `null`, целочисленный результат и описание бизнес-правил.

**Новое понятие:** `LocalDate` из `java.time` представляет календарную дату без времени суток и часового пояса. `ChronoUnit.DAYS` позволяет посчитать количество дней между двумя датами.

## Зачем это нужно

Банковское приложение показывает, через сколько дней будет выполнен запланированный перевод. Метод считает календарные дни, поэтому ему не нужны часы, минуты или часовые пояса. Дата перевода в прошлом для обратного отсчёта считается ошибочным входом.

## Учебный пример: начало игрового сезона

```java
import java.time.LocalDate;
import java.time.temporal.ChronoUnit;

public class GameSeasonDemo {
    public static void main(String[] args) {
        String todayText = "2026-11-25";
        String seasonText = "2026-12-01";

        LocalDate today = LocalDate.parse(todayText);
        LocalDate seasonStart = LocalDate.parse(seasonText);
        long daysLeft = ChronoUnit.DAYS.between(today, seasonStart);

        System.out.println(daysLeft);
    }
}
```

- Входные строки записаны в формате `год-месяц-день`.
- `LocalDate.parse(...)` превращает текстовую дату в объект, с которым Java может выполнять календарные операции.
- `ChronoUnit.DAYS.between(today, seasonStart)` считает полные переходы между календарными днями: от 25 ноября до 1 декабря — `6` дней.
- `System.out.println` показывает результат `6`. В задаче аналогичный расчёт будет выполняться для даты перевода.

## Условие

Создай публичный класс `TransferDateCalculator` в пакете `learning.task024` и публичный статический метод:

```java
long daysUntilTransfer(LocalDate today, LocalDate transferDate)
```

Метод возвращает количество календарных дней от `today` до `transferDate`.

- Если `transferDate` совпадает с `today`, верни `0`.
- Если дата перевода раньше `today`, выброси `IllegalArgumentException`: обратный отсчёт для прошедшего перевода не строится.
- Если любая дата равна `null`, выброси `IllegalArgumentException`.
- Используй `LocalDate` и `ChronoUnit.DAYS`; не заменяй даты строками, числами или устаревшим `Date`.

## Примеры

- `2026-11-25` → `2026-11-30` возвращает `5`.
- `2026-12-31` → `2027-01-01` возвращает `1`.
- `2024-02-28` → `2024-03-01` возвращает `2` (2024 год високосный).

## Критерии готовности

- Учти границы месяца, года и високосный день.
- Метод возвращает `long`, который выдаёт `ChronoUnit.DAYS.between`.
- Проверь обе даты на `null` и не допускай прошедшую дату перевода.
- Полный путь данных: строки дат → `LocalDate.parse` на стороне вызывающего кода → метод расчёта → число дней.
