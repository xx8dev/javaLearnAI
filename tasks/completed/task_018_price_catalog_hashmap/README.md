# Задача №18 — Как искать цену товара по коду?

**Сложность:** начальная, следующий шаг в теме коллекций.

**Тема:** хранение пары «код товара — цена» в `HashMap`.

## Что закрепляем и изучаем

- Закрепляем: классы, инкапсуляцию, строки, целочисленные ограничения, `equals()` и `hashCode()`.
- Новое понятие: `HashMap` — коллекция пар «ключ — значение». По ключу можно быстро получить значение; повторная запись того же ключа заменяет прежнее значение.

`HashMap` опирается на `hashCode()` ключа, чтобы найти нужное место, и на `equals()`, чтобы проверить, что ключи равны. Поэтому разные объекты `String` с одинаковым текстом обозначают один и тот же ключ. Порядок элементов `HashMap` не гарантирует.

## Учебный пример: очки игроков

```java
import java.util.HashMap;

public class PlayerScoresDemo {
    public static void main(String[] args) {
        HashMap<String, Integer> scores = new HashMap<>();
        scores.put("raven", 120);
        scores.put("orbit", 95);
        int ravenScore = scores.get("raven");
        scores.put("raven", 130);
        System.out.println(ravenScore + "; игроков: " + scores.size());
    }
}
```

- `HashMap<String, Integer>` хранит строковый логин игрока как ключ, а число очков — как значение.
- `put` связывает ключ со значением. Если ключ уже есть, новая запись заменяет прежнее значение, но не добавляет второй такой ключ.
- `get("raven")` получает очки по ключу; сохранённое в `ravenScore` значение остаётся `120`, даже когда карта позже обновляется до `130`.
- `size()` сообщает число разных ключей. Программа выведет `120; игроков: 2`.

Путь данных здесь такой: логин и очки передаются в `put` → карта сохраняет пару → `get` находит очки по логину → результат выводится. В задаче похожим образом нужно связать код товара с его ценой.

## Условие

Создай публичный класс `PriceCatalog` в пакете `learning.task018`. Каталог хранит цену каждого товара по его коду. Используй одно закрытое поле `HashMap<String, Integer>` и не возвращай наружу саму карту.

Внешний контракт:

```java
public PriceCatalog()
public void setPrice(String productCode, int priceRubles)
public int getPrice(String productCode)
public boolean removePrice(String productCode)
public int getProductCount()
```

Правила:

- Код товара во всех методах должен быть не `null` и не пустой строкой. Иначе выбрасывается `IllegalArgumentException`.
- Цена находится в диапазоне `0..1_000_000` включительно. `setPrice` отклоняет цену вне диапазона через `IllegalArgumentException` и не меняет каталог.
- Повторный `setPrice` для того же кода обновляет цену существующего товара; число разных товаров не увеличивается.
- `getPrice` возвращает цену или `-1`, если код не найден. Нулевая цена допустима и отличается от отсутствующего товара.
- `removePrice` возвращает `true`, если товар был удалён, и `false`, если такого кода не было.
- Коды сравниваются с учётом регистра. Каталоги, созданные разными объектами, независимы; методы ничего не печатают.

### Примеры

| Операции | Результат |
|---|---|
| Сохранить `"FILM-7" → 350`, затем запросить `"FILM-7"` | `350` |
| Сохранить `"GAME-2" → 700`, затем заменить цену на `750` | В каталоге одна запись с ценой `750` |
| Запросить неизвестный код | `-1` |

## Критерии готовности

- Каталог хранит пары в закрытом `HashMap<String, Integer>` и не отдаёт карту вызывающему коду.
- Ключи проверяются, цены ограничены включительным диапазоном `0..1_000_000`.
- Обновление, поиск и удаление работают по равенству ключей; отсутствующая цена отличается от цены `0`.
- Проверены обычные случаи, границы, неизвестные коды, `null`, пустые строки и независимость каталогов.
- Все автоматические тесты проходят.
