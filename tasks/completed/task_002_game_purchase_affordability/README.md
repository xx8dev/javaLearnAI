# Задача №2 — Достаточно ли средств для покупки?

**Сложность:** начальная.

**Тема:** проверка оплаты внутриигровой покупки.

## Что закрепляем и изучаем

- Закрепляем: `int`, арифметические значения и метод с параметрами и возвращаемым результатом.
- Новые понятия: логический тип `boolean`; сравнение чисел оператором `>=`.

Тип `boolean` хранит один из двух ответов: `true` (да) или `false` (нет). Сравнение `a >= b` даёт такой ответ: оно истинно, если `a` больше `b` или равен ему. Это удобно для финансового правила, где точной суммы на счёте достаточно для оплаты.

## Условие

Игрок хочет купить предмет за указанную цену. Проверь, достаточно ли на его игровом счёте денег для покупки. Если баланс равен цене, оплата разрешена. Если баланс меньше цены, денег не хватает.

Создай в пакете `learning.task002` публичный класс `learning.task002.Solution` и метод с точной сигнатурой:

```java
public static boolean canMakePurchase(int balanceRubles, int priceRubles)
```

Метод возвращает `true`, если покупка доступна, иначе `false`. Он только сообщает результат проверки и не меняет баланс. Не читай ввод с клавиатуры и не печатай результат.

### Примеры

| Баланс | Цена | Результат |
|---:|---:|:---|
| 1 200 | 800 | `true` |
| 500 | 500 | `true` |
| 499 | 500 | `false` |

## Ограничения и готовность

- Баланс и цена находятся в диапазоне от `0` до `1 000 000 000` рублей включительно.
- Нулевая цена допустима: бесплатную покупку можно совершить при любом допустимом балансе.
- Точное равенство баланса и цены разрешает покупку.
- Верни значение типа `boolean` из метода; не создавай состояние счёта и не изменяй входные значения.
- Задача готова, когда все автоматические тесты проходят.

## Учебный пример: хватит ли мест в кинозале

Метод проверяет, хватит ли мест для группы зрителей. Это правило из той же области, но оно сравнивает вместимость с размером группы. Оператор `>=` даёт `true`, когда мест столько же или больше, чем зрителей.

```java
public class CinemaExample {
    public static void main(String[] args) {
        boolean enoughSeats = hasEnoughSeats(40, 4);
        System.out.println(enoughSeats);
    }

    public static boolean hasEnoughSeats(int seatCount, int groupSize) {
        return seatCount >= groupSize;
    }
}
```

- `boolean enoughSeats` хранит ответ на вопрос, поместится ли группа.
- `hasEnoughSeats(40, 4)` передаёт в метод 40 мест и 4 зрителя.
- `seatCount >= groupSize` сравнивает числа и даёт `true`, потому что 40 больше 4.
- `return seatCount >= groupSize;` сразу возвращает ответ сравнения; для этого не требуется отдельная конструкция `if`.
- `System.out.println(enoughSeats);` печатает наблюдаемый результат `true`.

Путь данных в примере: поступают `40` мест и группа из `4` зрителей → Java сравнивает числа оператором `>=` → метод возвращает `true` → программа печатает `true`.

В задаче тест передаст балансы и цены методу `canMakePurchase`, получит `true` или `false` и сравнит ответ с ожидаемым. Проверки равенства, нехватки денег и нулевых значений подготовлены заранее.
