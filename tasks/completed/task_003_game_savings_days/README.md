# Задача №3 — Сколько игровых дней копить на предмет?

**Сложность:** начальная.

**Тема:** накопления в игровом счёте.

## Что закрепляем и изучаем

- Закрепляем: `int`, арифметику, методы с параметрами, `boolean` и сравнения.
- Новые понятия: ветвление `if`; цикл `while`.

`if` выбирает действие по результату логического выражения: например, уже хватает денег или ещё нет. `while` повторяет действия, пока условие истинно. В цикле важно менять данные так, чтобы условие в итоге стало ложным; иначе программа может повторяться бесконечно.

## Условие

Игрок копит на предмет. В начале каждого игрового дня на счёт начисляется одинаковая награда. Определи, сколько дней пройдёт, прежде чем баланс станет не меньше цены.

Создай с нуля пакет `learning.task003`, публичный класс `Solution` и метод с точной сигнатурой:

```java
public static int daysUntilAffordable(int balanceRubles, int priceRubles, int dailyRewardRubles)
```

Метод должен вернуть:

- `0`, если денег уже хватает, включая бесплатный предмет;
- число дней, необходимых для накопления;
- `-1`, если денег не хватает, а ежедневная награда равна `0` — накопить невозможно.

Баланс, цена и награда находятся в диапазоне от `0` до `100 000` рублей включительно. Не читай данные с клавиатуры и не печатай результат. Для решения обязательно используй цикл `while`.

### Примеры

| Баланс | Цена | Награда за день | Результат |
|---:|---:|---:|---:|
| 400 | 1 000 | 300 | `2` |
| 1 000 | 900 | 0 | `0` |
| 0 | 1 000 | 0 | `-1` |

## Учебный пример: за сколько вечеров посмотреть подборку фильмов

Зритель смотрит несколько фильмов за вечер. Метод считает, сколько вечеров понадобится, чтобы посмотреть всю подборку. Этот пример показывает те же `if` и `while`, но не решает задачу про игровой баланс.

```java
public class CinemaExample {
    public static void main(String[] args) {
        int evenings = eveningsToFinishCollection(1, 5, 2);
        System.out.println(evenings);
    }

    public static int eveningsToFinishCollection(int watchedMovies, int totalMovies, int moviesPerEvening) {
        if (moviesPerEvening <= 0) {
            return -1;
        }

        int evenings = 0;
        while (watchedMovies < totalMovies) {
            watchedMovies = watchedMovies + moviesPerEvening;
            evenings = evenings + 1;
        }
        return evenings;
    }
}
```

- `eveningsToFinishCollection(1, 5, 2)` передаёт методу: уже просмотрен 1 фильм, всего их 5, за вечер смотрят 2.
- `if (moviesPerEvening <= 0)` проверяет, можно ли продвигаться. При нуле или отрицательном значении метод сразу возвращает `-1`.
- `while (watchedMovies < totalMovies)` повторяет тело цикла, пока просмотренных фильмов меньше общего числа.
- `watchedMovies = watchedMovies + moviesPerEvening;` увеличивает число просмотренных фильмов, поэтому условие цикла со временем станет ложным.
- `evenings = evenings + 1;` считает выполненные повторы цикла.
- Метод возвращает `2`, а `System.out.println(evenings)` печатает `2`.

Путь данных: в метод поступают `1`, `5` и `2` → проверка `if` пропускает допустимую скорость просмотра → цикл меняет количество фильмов `1 → 3 → 5` и считает вечера `0 → 1 → 2` → метод возвращает `2` → программа печатает `2`.

## Ограничения и готовность

- Все три входных значения находятся в диапазоне от `0` до `100 000` включительно.
- Начисление происходит один раз за каждый целый день; неполного дня в ответе нет.
- Если баланс уже достиг цены, результат равен `0`, даже когда награда равна нулю.
- Если баланс ниже цены и награда равна нулю, результат равен `-1`.
- Используй `while`; цикл должен изменять баланс и счётчик дней.
- Метод возвращает результат и не использует консоль.
- Задача готова, когда все автоматические тесты проходят и решение соблюдает ограничение на цикл.
