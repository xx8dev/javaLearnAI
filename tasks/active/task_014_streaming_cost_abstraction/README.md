# Задача №14 — Что выгоднее: оплата за часы просмотра или месячный тариф?

**Сложность:** начальная, новый шаг в объектно-ориентированном программировании.

**Тема:** расчёт стоимости просмотра по разным тарифам.

## Что закрепляем и изучаем

- Закрепляем: наследование, переопределение методов и полиморфный вызов через базовый тип.
- Новое понятие: абстрактный класс и абстрактный метод.

Абстрактный класс задаёт общую роль для нескольких конкретных классов, но сам по себе не описывает готовое поведение. Его нельзя создать через `new`. Абстрактный метод объявлен без тела, поэтому конкретный класс-наследник должен переопределить его, прежде чем его объект можно будет создать.

## Учебный пример: правила платы за парковку

```java
abstract class ParkingFeeRule {
    abstract int calculate(int parkedHours);
}

class HourlyParkingFeeRule extends ParkingFeeRule {
    @Override
    int calculate(int parkedHours) {
        return parkedHours * 40;
    }
}

class FlatParkingFeeRule extends ParkingFeeRule {
    @Override
    int calculate(int parkedHours) {
        return 300;
    }
}

public class Demo {
    public static void main(String[] args) {
        int parkedHours = 2;
        ParkingFeeRule selectedRule = new HourlyParkingFeeRule();
        int fee = selectedRule.calculate(parkedHours);
        System.out.println(fee);
    }
}
```

- `ParkingFeeRule` объявляет обязательный метод `calculate`, но не задаёт его тело. Поэтому `new ParkingFeeRule()` написать нельзя.
- `HourlyParkingFeeRule` и `FlatParkingFeeRule` наследуются от базового класса и каждый задаёт собственный вариант метода.
- `@Override` просит Java проверить, что метод наследника совпадает с методом базового класса.
- `selectedRule` имеет общий тип, но хранит объект почасового правила. При двух часах его метод возвращает `80`; `println` показывает результат.
- Если передать в `selectedRule` объект `FlatParkingFeeRule`, вызов того же метода вернёт `300`.

Путь значения: выбранное правило и число часов → вызов общего метода → реализация конкретного тарифа → возвращённая цена → вывод.

## Условие

Создай абстрактный публичный класс `ViewingCostRule` и два публичных класса-наследника в пакете `learning.task014`.

Базовый класс объявляет публичный абстрактный метод:

```java
public abstract int calculateCostRubles(int viewingHours);
```

Правила тарифов:

- `HourlyViewingCostRule` берёт `12` рублей за каждый час просмотра.
- `MonthlyViewingCostRule` возвращает фиксированную стоимость месячного тарифа `450` рублей, независимо от числа часов.

Количество часов всегда целое и находится в диапазоне `0..1_000` включительно. Проверять входные данные не нужно. Методы ничего не печатают и не хранят состояние.

### Примеры

| Тариф | Часы просмотра | Стоимость |
|---|---:|---:|
| почасовой | `0` | `0` |
| почасовой | `3` | `36` |
| месячный | `0` | `450` |
| месячный | `100` | `450` |

## Файлы и внешний контракт

Самостоятельно создай отдельный файл для каждого публичного класса:

```text
src/main/java/learning/task014/ViewingCostRule.java
src/main/java/learning/task014/HourlyViewingCostRule.java
src/main/java/learning/task014/MonthlyViewingCostRule.java
```

Общий тип `ViewingCostRule` должен быть абстрактным. Оба наследника должны переопределять `calculateCostRubles(int viewingHours)` и возвращать цену по своему правилу. Тесты также вызовут метод у объектов через переменную типа `ViewingCostRule`, чтобы проверить выбор нужной реализации.

## Критерии готовности

- `ViewingCostRule` — публичный абстрактный класс с публичным абстрактным методом.
- Оба тарифа — публичные классы-наследники, каждый переопределяет метод.
- Почасовая и месячная стоимость правильны на обычных значениях и границах диапазона.
- Полиморфный вызов через переменную типа `ViewingCostRule` работает для обоих тарифов.
- Объекты не хранят состояние; методы не печатают результат.
- Все автоматические тесты проходят.

Тесты тренера находятся по пути `src/test/java/learning/task014/Task014StreamingCostAbstractionTest.java`. Запусти их из корня проекта:

```shell
.\mvnw.cmd test
```

Пока классы решения не созданы, тесты ожидаемо не скомпилируются. Условие не содержит заготовок: пакеты, файлы и реализацию создай сам.
