# Задача №7 — Сколько стоит заказ билетов?

**Сложность:** начальная.

**Тема:** заказ билетов в кинотеатр.

## Что закрепляем и изучаем

- Закрепляем: `int`, арифметику и методы с параметрами.
- Новое понятие: класс и объект. Объект хранит значения в полях, а его методы работают с этими значениями.

Класс описывает новый вид сущности программы. По классу можно создать несколько объектов: каждый хранит свои данные. Конструктор запускается при создании объекта и записывает начальные значения; обычный метод объекта использует их при расчёте.

## Условие

Покупатель оформляет заказ на билеты в кино. Заказ хранит количество билетов и цену одного билета. Создай класс `TicketOrder` в пакете `learning.task007` с таким внешним контрактом:

```java
public TicketOrder(int ticketCount, int ticketPriceRubles)
public int totalCost()
public boolean fitsBudget(int budgetRubles)
```

Конструктор получает количество билетов от `0` до `50` и цену от `0` до `10 000` рублей. Эти значения всегда находятся в указанном диапазоне. Метод `totalCost()` возвращает стоимость всех билетов. Метод `fitsBudget(budgetRubles)` возвращает `true`, если бюджет неотрицательный и не меньше стоимости заказа; иначе возвращает `false`.

Это методы объекта, поэтому не объявляй их `static`. При создании двух заказов каждый объект должен хранить собственные количество билетов и цену. Класс не должен читать ввод или печатать результат.

### Примеры

| Заказ | Бюджет | Стоимость | `fitsBudget` |
|---|---:|---:|:---:|
| 3 билета по 450 ₽ | `1 350` | `1 350` | `true` |
| 3 билета по 450 ₽ | `1 000` | `1 350` | `false` |
| 0 билетов по 500 ₽ | `0` | `0` | `true` |

## Учебный пример: награда за игровой уровень

Класс `GameReward` описывает награду с базовыми очками и бонусом. Конструктор сохраняет значения конкретной награды, а метод объекта возвращает их сумму.

```java
public class GameReward {
    private int basePoints;
    private int bonusPoints;

    public GameReward(int base, int bonus) {
        basePoints = base;
        bonusPoints = bonus;
    }

    public int totalPoints() {
        return basePoints + bonusPoints;
    }

    public static void main(String[] args) {
        GameReward reward = new GameReward(10, 5);
        System.out.println(reward.totalPoints());
    }
}
```

- `class GameReward` объявляет новый тип объектов.
- `basePoints` и `bonusPoints` — поля: они хранят данные конкретного объекта.
- `new GameReward(10, 5)` создаёт объект и запускает конструктор; параметры `base` и `bonus` записываются в его поля.
- `reward.totalPoints()` вызывает метод именно у объекта `reward`; метод складывает `10` и `5` и возвращает `15`.
- `System.out.println(...)` показывает результат `15` в консоли.

Путь данных: аргументы конструктора `10` и `5` → конструктор записывает их в поля объекта → `totalPoints()` складывает значения → возвращает `15` → программа печатает `15`.

## Ограничения и готовность

- Создай класс в отдельном файле `TicketOrder.java`; не вкладывай его в другой класс.
- Точные имена класса, конструктора и методов обязательны, потому что по ним тесты создают объект и проверяют его поведение.
- Значения конструктора гарантированно лежат в допустимых диапазонах; дополнительную обработку ошибочных значений конструктора добавлять не нужно.
- Нулевое количество билетов и нулевая цена допустимы.
- Проверь, что два разных объекта не используют данные друг друга.
- Класс не использует консоль.
- Задача готова, когда все тесты проходят и контракт класса соблюдён.
