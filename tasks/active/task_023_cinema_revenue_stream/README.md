# Задача №23 — Сколько выручили за билеты от заданной цены?

**Сложность:** начальная, обработка списка через Stream API.

**Закрепляем:** `List`, лямбда-выражения, `Predicate`, проверку входных данных и тип `long` для суммы.

**Новое понятие:** Stream API позволяет описать последовательные шаги обработки элементов коллекции: выбрать нужные элементы, преобразовать их и получить итог. Поток обрабатывает элементы, но сам по себе не меняет исходный список.

## Зачем это нужно

Кинотеатру нужно быстро собрать выручку от билетов не дешевле заданной цены. Если отчёт строится за длинный период, сумма нескольких цен может превысить диапазон `int`, поэтому итог возвращается как `long`.

## Учебный пример: сумма игровых покупок от порога

```java
import java.util.List;

public class GamePurchaseSummary {
    public static void main(String[] args) {
        List<Integer> purchasePrices = List.of(250, 500, 350);
        int minimumPrice = 300;

        long total = purchasePrices.stream()
                .filter(price -> price >= minimumPrice)
                .mapToLong(price -> price.longValue())
                .sum();

        System.out.println(total);
    }
}
```

- `purchasePrices.stream()` начинает обработку элементов списка по очереди.
- `filter(...)` оставляет покупки, удовлетворяющие условию `price >= minimumPrice`. Порог включён: покупка ровно за 300 тоже остаётся.
- `mapToLong(...)` преобразует каждую выбранную цену из `Integer` в `long`, чтобы сумма не переполнилась как `int`.
- `sum()` складывает выбранные значения. Для `[250, 500, 350]` и порога `300` программа выводит `850`.
- Исходный список не меняется; вычисления идут по потоку и возвращают число.

## Условие

Создай публичный класс `CinemaRevenueSummary` в пакете `learning.task023` и публичный статический метод:

```java
long sumTicketsAtLeast(List<Integer> ticketPrices, int minimumPrice)
```

Метод получает цены билетов в целых рублях и порог цены. Рассчитай сумму только тех цен, которые больше или равны порогу. Для подсчёта обязательно используй Stream API: отбор, преобразование элементов в `long` и суммирование.

Входные ограничения:

- `ticketPrices` не должен быть `null`; каждый элемент должен быть не `null` и неотрицательным; `minimumPrice` тоже должен быть неотрицательным. При нарушении выброси `IllegalArgumentException`.
- Пустой список или отсутствие цен, прошедших порог, дают сумму `0`.
- Список цен не должен изменяться.

## Примеры

- `[250, 500, 350]`, порог `300` → `850`.
- `[300, 400]`, порог `300` → `700`.
- `[100, 200]`, порог `500` → `0`.

## Критерии готовности

- Цена, равная порогу, включается в сумму.
- Сумма возвращается как `long`; например, сумма двух цен `Integer.MAX_VALUE` больше максимального значения `int`.
- Метод не использует циклы для подсчёта и не меняет входной список.
- Объясни путь данных: список → поток → отбор по порогу → преобразование в `long` → сумма.
