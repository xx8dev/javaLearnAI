# Задача №4 — Какая выручка была за кинопоказы?

**Сложность:** начальная.

**Тема:** выручка нескольких сеансов кинотеатра.

## Что закрепляем и изучаем

- Закрепляем: `int`, методы, `if` и цикл `while`.
- Новое понятие: массив чисел `int[]` и доступ к его элементам по индексу.

Массив хранит несколько значений одного типа под одним именем. У каждого элемента есть индекс: в Java первый индекс — `0`, а последний — `length - 1`. Так можно обработать список выручки сеансов, не создавая отдельную переменную для каждого показа.

## Условие

Кинотеатр хранит выручку каждого сеанса в рублях. Получив массив сумм, вычисли общую выручку.

Создай с нуля пакет `learning.task004`, публичный класс `Solution` и метод с точной сигнатурой:

```java
public static int totalTicketRevenue(int[] sessionRevenueRubles)
```

Верни сумму всех элементов. Пустой массив означает, что сеансов ещё не было, и для него результат равен `0`. Если в массиве встретилась отрицательная сумма, верни `-1`. Не изменяй массив, не читай ввод с клавиатуры и не печатай результат. Для практики обязательно используй цикл `while`.

Длина массива находится в диапазоне от `0` до `1 000` включительно. Каждая корректная сумма — от `0` до `1 000 000` рублей; общая сумма помещается в `int`.

### Примеры

| Выручка по сеансам | Результат |
|:---|---:|
| `[12 000, 0, 18 500]` | `30 500` |
| `[]` | `0` |
| `[2 000, -1, 3 000]` | `-1` |

## Учебный пример: очки за игровые раунды

Игра записывает очки, полученные в каждом раунде. Метод складывает значения массива и возвращает общий результат. Здесь используется тот же массив и цикл, но предметная область отличается от задачи.

```java
public class GameScoreExample {
    public static void main(String[] args) {
        int[] pointsByRound = {7, 0, 12};
        int totalPoints = sumRoundPoints(pointsByRound);
        System.out.println(totalPoints);
    }

    public static int sumRoundPoints(int[] pointsByRound) {
        int total = 0;
        int index = 0;
        while (index < pointsByRound.length) {
            total = total + pointsByRound[index];
            index = index + 1;
        }
        return total;
    }
}
```

- `int[] pointsByRound = {7, 0, 12};` создаёт массив из трёх целых чисел.
- `sumRoundPoints(pointsByRound)` передаёт весь массив в метод.
- `int index = 0;` начинает обход с первого элемента, потому что его индекс равен нулю.
- `while (index < pointsByRound.length)` повторяет тело, пока индекс меньше длины массива.
- `pointsByRound[index]` читает значение по текущему индексу.
- `total = total + pointsByRound[index];` добавляет очки текущего раунда к общей сумме.
- `index = index + 1;` переходит к следующему элементу, а `return total;` возвращает сумму `19`.
- `System.out.println(totalPoints);` печатает `19`.

Путь данных: в метод поступает `[7, 0, 12]` → цикл читает значения с индексами `0`, `1`, `2` и складывает их (`0 → 7 → 7 → 19`) → метод возвращает `19` → программа печатает `19`.

## Ограничения и готовность

- Массив не равен `null`; длина и корректные суммы находятся в указанных диапазонах.
- Пустой массив даёт `0`.
- Отрицательная сумма — ошибочное значение, для которого метод возвращает `-1`.
- Входной массив нельзя менять.
- Для обработки элементов используй `while`; тесты проверяют результат, а соблюдение этого ограничения будет проверено при разборе кода.
- Метод не использует консоль.
- Задача готова, когда все автоматические тесты проходят и решение соблюдает ограничение на цикл.
