# Задача №16 — Как найти товар в каталоге разных типов?

**Сложность:** начальная, следующий шаг в теме обобщений.

**Тема:** один статический метод для поиска значения в массивах разных типов.

## Что закрепляем и изучаем

- Закрепляем: массивы, циклы, `static`, сравнение объектов через `equals()` и обработку `null`.
- Новое понятие: обобщённый метод. В отличие от задачи про обобщённый класс, тип-параметр здесь принадлежит одному методу.

## Учебный пример: выбрать один из двух бонусов

```java
public class BonusChoiceDemo {
    public static <T> T chooseFirst(T first, T second) {
        return first;
    }

    public static void main(String[] args) {
        String soundtrack = chooseFirst("Тема фильма", "Тема игры");
        Integer points = chooseFirst(20, 40);
        System.out.println(soundtrack);
        System.out.println(points);
    }
}
```

- `<T>` перед типом результата объявляет параметр типа именно для метода `chooseFirst`.
- Оба аргумента и результат имеют один тип `T`, поэтому метод нельзя вызвать, например, со строкой и числом вместе.
- В первом вызове Java выводит `T` как `String`, во втором — как `Integer`; код метода при этом один.
- При запуске метод возвращает первый аргумент, а `println` выводит `Тема фильма` и `20`.

## Условие

Создай публичный класс `CatalogSearch` в пакете `learning.task016`. В нём должен быть один публичный статический обобщённый метод:

```java
public static <T> int findFirstIndex(T[] items, T target)
```

Метод ищет первое значение, равное `target`, и возвращает его индекс. Если совпадения нет, верни `-1`. Сравнивай значения по смыслу `equals()`, а не только проверкой, ссылаются ли переменные на один объект.

Правила:

- Массив не должен быть `null`; если он `null`, метод выбрасывает `IllegalArgumentException`.
- Элементы массива и искомое значение могут быть `null`. Два значения `null` считаются совпадением; `null` и не-null значение не совпадают.
- Если одинаковое значение встречается несколько раз, верни индекс первого совпадения.
- Массив не изменяется. Метод и класс не хранят состояние и ничего не печатают.

### Примеры

| Массив | Искомое значение | Результат |
|---|---|---:|
| `{"Фильм", "Игра"}` | `"Игра"` | `1` |
| `{10, 20, 20}` | `20` | `1` |
| `{"Фильм"}` | `"Сериал"` | `-1` |

Компилятор должен выводить общий тип из массива и искомого значения: вызов со `String[]` ищет строку, а вызов с `Integer[]` — число. Метод нельзя заменять отдельными версиями для разных типов.

## Критерии готовности

- `findFirstIndex` — публичный статический обобщённый метод с одним тип-параметром `T`.
- Метод работает с разными ссылочными типами, находит первое совпадение по `equals()` и возвращает `-1`, если его нет.
- Корректно обрабатываются пустой массив, повторяющиеся значения и `null`-элементы; для массива `null` выбрасывается `IllegalArgumentException`.
- Поиск не изменяет массив и не печатает результат.
- Все автоматические тесты проходят.
