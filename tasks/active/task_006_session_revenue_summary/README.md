# Задача №6 — Как посчитать выручку нескольких кинопоказов?

**Сложность:** начальная.

**Тема:** общий доход кинотеатра по числу проданных билетов на каждом сеансе.

## Что закрепляем и изучаем

- Закрепляем: массивы `int[]`, проверку входных данных, индексы, цикл `while` и арифметику.
- Новое понятие: декомпозиция — разделение расчёта на отдельные методы.

Когда один и тот же небольшой расчёт нужен для каждого элемента списка, его удобно вынести в отдельный метод. Основной метод перебирает сеансы и складывает результат, а вспомогательный рассчитывает выручку одного сеанса. Так каждая часть кода отвечает за одну понятную операцию.

## Условие

В кинотеатре несколько сеансов проходят по одной цене билета. Дан массив, где каждый элемент — количество проданных билетов на соответствующем сеансе. Рассчитай общую выручку.

Создай с нуля пакет `learning.task006`, публичный класс `Solution` и метод с точной сигнатурой:

```java
public static int calculateTotalRevenue(int[] ticketsSoldBySession, int ticketPriceRubles)
```

Метод должен пройти массив и сложить выручку сеансов. Раздели работу на два метода: основной метод обрабатывает массив, а выбранный тобой вспомогательный метод рассчитывает выручку одного сеанса по числу проданных билетов и цене. Основной метод должен вызывать вспомогательный для каждого элемента массива. Имя и область видимости вспомогательного метода выбери самостоятельно.

Допустимая длина массива — от `0` до `100`; число проданных билетов на одном сеансе — от `0` до `1 000`; цена билета — от `0` до `10 000` рублей. Верни `-1`, если массив равен `null`, его длина больше `100` или любое число находится вне диапазона. Пустой массив допустим и даёт `0`. Входной массив нельзя изменять, консоль использовать нельзя. Максимальная выручка равна `1 000 000 000` рублей и помещается в `int`.

### Примеры

| Билеты по сеансам | Цена билета | Результат |
|:---|---:|---:|
| `[4, 2, 0]` | `450` | `2 700` |
| `[]` | `900` | `0` |
| `[3, -1]` | `500` | `-1` |

## Учебный пример: очки за игровые матчи

Игра начисляет очки за передачи в каждом матче. Вспомогательный метод считает очки одного матча, а основной суммирует результаты по массиву матчей. Это показывает разбиение одной задачи на повторяемую операцию и общий расчёт.

```java
public class MatchScoreExample {
    public static void main(String[] args) {
        int[] assistsByMatch = {2, 1, 3};
        int seasonPoints = calculateSeasonPoints(assistsByMatch, 4);
        System.out.println(seasonPoints);
    }

    public static int calculateSeasonPoints(int[] assistsByMatch, int pointsPerAssist) {
        int totalPoints = 0;
        int matchIndex = 0;
        while (matchIndex < assistsByMatch.length) {
            totalPoints = totalPoints + pointsForOneMatch(assistsByMatch[matchIndex], pointsPerAssist);
            matchIndex = matchIndex + 1;
        }
        return totalPoints;
    }

    private static int pointsForOneMatch(int assists, int pointsPerAssist) {
        return assists * pointsPerAssist;
    }
}
```

- `assistsByMatch` хранит количество передач отдельно для каждого матча.
- `calculateSeasonPoints(assistsByMatch, 4)` получает массив и число очков за одну передачу.
- Цикл с `matchIndex` проходит матчи по очереди; вспомогательный метод получает число передач текущего матча и ставку очков.
- `pointsForOneMatch` отвечает только за расчёт одного матча: например, `2 * 4` даёт `8` очков.
- Основной метод складывает результаты `8`, `4` и `12`, затем возвращает `24`; `println` выводит `24`.

Путь данных: массив передач `[2, 1, 3]` и ставка `4` → для каждого матча вспомогательный метод считает очки → основной метод складывает их (`8 + 4 + 12`) → возвращает `24` → программа печатает `24`.

## Ограничения и готовность

- Массив может быть `null`; в этом случае метод возвращает `-1`.
- Пустой массив и нулевые значения допустимы.
- Выручка каждого сеанса должна считаться во вспомогательном методе, который вызывает основной метод.
- Не изменяй массив, не читай ввод и не печатай результат.
- Структуру из основного и вспомогательного методов проверим при разборе кода; автоматические тесты проверяют поведение внешнего метода.
- Задача готова, когда все автоматические тесты проходят и структура соответствует условию.
