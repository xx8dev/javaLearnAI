# Задача №26 — Как сообщить, что билет по цене не найден?

**Сложность:** начальная, поиск первого подходящего элемента через Stream API.

**Закрепляем:** `List`, лямбды, `filter`, сохранение порядка и JUnit 5.

**Новое понятие:** `Optional<T>` — контейнер, в котором либо есть значение типа `T`, либо значения нет. Stream-операция `findFirst()` возвращает `Optional`, потому что совпадение может не найтись.

## Зачем это нужно

Если кинотеатр ищет билет не дороже бюджета, подходящая цена может быть найдена, а может отсутствовать. `Optional` позволяет явно представить оба результата: найденную цену или отсутствие результата, не используя `null`.

## Учебный пример: найти первый фильм на букву A

```java
import java.util.List;
import java.util.Optional;

public class FilmTitleSearchDemo {
    public static void main(String[] args) {
        List<String> titles = List.of("Dune", "Arrival", "Alien");

        Optional<String> firstA = titles.stream()
                .filter(title -> title.startsWith("A"))
                .findFirst();

        String message = firstA.orElse("Фильм не найден");
        System.out.println(message);
    }
}
```

- Исходный список содержит названия в определённом порядке.
- `filter` оставляет названия, начинающиеся на `A`.
- `findFirst()` берёт первое совпадение в исходном порядке и помещает его в `Optional<String>`.
- `orElse(...)` извлекает найденное название или подставляет сообщение, если совпадений нет.
- Для списка из примера выводится `Arrival`; если поменять условие на букву `Z`, будет выведено `Фильм не найден`.

## Условие

Создай публичный класс `TicketPriceSearch` в пакете `learning.task026` и публичный статический метод:

```java
Optional<Integer> findFirstAtMost(List<Integer> prices, int maxPrice)
```

Метод должен вернуть цену первого билета, которая меньше или равна `maxPrice`. Порядок списка важен: верни первое совпадение, а не минимальную цену.

- Используй Stream API: `filter` и `findFirst`.
- Если подходящей цены нет или список пуст, верни `Optional.empty()` через результат `findFirst()`.
- Если список или элемент равен `null`, либо цена билета или `maxPrice` отрицательны, выброси `IllegalArgumentException`.
- Не меняй исходный список и не возвращай `null` вместо `Optional`.

## Примеры

- Цены `[500, 250, 200]`, предел `300` → найден первый подходящий билет `250`.
- Цены `[500, 400]`, предел `300` → `Optional.empty()`.
- Цены `[250]`, предел `250` → цена `250` подходит, так как предел включён.

## Критерии готовности

- Найди первое совпадение по порядку списка.
- Различай `Optional` с найденной ценой и пустой `Optional`.
- Не используй `null` как результат поиска.
- Проверь обычный поиск, совпадение на границе, отсутствие совпадений, пустой список и ошибки входных данных.
