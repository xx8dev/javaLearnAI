# Задача №5 — Сколько заработал кинотеатр при полной посадке?

**Сложность:** начальная.

**Тема:** выручка кинотеатра по числу рядов, мест и цене билета.

## Что закрепляем и изучаем

- Закрепляем: `int`, параметры метода, проверки `if` и цикл `while`.
- Новое понятие: вложенные циклы `while`.

Вложенный цикл находится внутри другого цикла. Внешний цикл обрабатывает один ряд за раз, а внутренний проходит все места этого ряда. После завершения внутреннего цикла внешний переходит к следующему ряду, и счётчик мест начинается заново.

## Условие

Кинотеатр хочет оценить выручку при полной посадке. Известны количество рядов, число мест в каждом ряду и цена одного билета. Посчитай выручку, прибавляя цену билета за каждое место.

Создай с нуля пакет `learning.task005`, публичный класс `Solution` и метод с точной сигнатурой:

```java
public static int calculateFullSeatRevenue(int rowCount, int seatsPerRow, int ticketPriceRubles)
```

Верни общую выручку. Допустимые значения: от `0` до `100` рядов, от `0` до `100` мест в ряду и от `0` до `1 000` рублей за билет. Если хотя бы один аргумент находится вне своего диапазона, верни `-1`. Ноль рядов, ноль мест или нулевая цена допустимы и дают выручку `0`.

Для расчёта обязательно используй два вложенных цикла `while`: внутренний цикл должен обработать места текущего ряда, внешний — все ряды. Не используй консоль. Максимальная выручка равна `10 000 000` рублей и помещается в `int`.

### Примеры

| Ряды | Мест в ряду | Цена билета | Результат |
|---:|---:|---:|---:|
| `3` | `4` | `450` | `5 400` |
| `0` | `5` | `700` | `0` |
| `2` | `4` | `0` | `0` |
| `2` | `-1` | `500` | `-1` |

## Учебный пример: очки в игровых раундах

В игре каждый участник получает по одному очку за каждый пройденный раунд. Внешний цикл перебирает раунды, а внутренний — участников. Пример считает очки в отдельной игровой ситуации и не решает задачу о выручке.

```java
public class GameRoundsExample {
    public static void main(String[] args) {
        int totalPoints = countParticipationPoints(2, 3);
        System.out.println(totalPoints);
    }

    public static int countParticipationPoints(int roundCount, int playersPerRound) {
        int totalPoints = 0;
        int round = 0;
        while (round < roundCount) {
            int player = 0;
            while (player < playersPerRound) {
                totalPoints = totalPoints + 1;
                player = player + 1;
            }
            round = round + 1;
        }
        return totalPoints;
    }
}
```

- `countParticipationPoints(2, 3)` передаёт в метод два раунда и по три участника в каждом.
- `int round = 0;` задаёт номер текущего раунда. Условие внешнего `while` повторяет его обработку дважды.
- `int player = 0;` находится внутри внешнего цикла, поэтому для каждого нового раунда счёт участников начинается с нуля.
- Внутренний `while` выполняется три раза и добавляет по одному очку за каждого участника.
- После внутреннего цикла `round = round + 1;` переводит внешний цикл к следующему раунду.
- Метод возвращает `6`, а `System.out.println(totalPoints);` выводит `6`.

Путь данных: аргументы `2` и `3` → два раунда, в каждом учитываются три участника → накапливается `6` очков → метод возвращает `6` → программа печатает `6`.

## Ограничения и готовность

- Аргументы могут быть любыми значениями `int`; значения вне заданных диапазонов дают `-1`.
- Нулевые значения допустимы.
- Расчёт должен использовать два вложенных цикла `while`; это требование также проверяется при разборе кода.
- Метод не читает ввод и не печатает результат.
- Задача готова, когда все автоматические тесты проходят и решение соблюдает ограничение на циклы.
